# 📝 Flask Todo App

یک اپلیکیشن ساده و کاربردی برای مدیریت کارهای روزانه، ساخته‌شده با Python و Flask.

## 🔗 دموی آنلاین
👉 **[مشاهده دمو](https://YS14.pythonanywhere.com)**

## ✨ امکانات
- ✅ افزودن کار جدید
- ✅ علامت زدن کار به عنوان انجام‌شده
- ✅ حذف کار
- ✅ رابط کاربری فارسی و راست‌چین
- ✅ بدون نیاز به دیتابیس (برای شروع)

## 🛠 تکنولوژی‌ها
| تکنولوژی | کاربرد |
|----------|--------|
| Python 3.10 | زبان اصلی |
| Flask 3.0 | وب فریمورک |
| HTML/CSS | رابط کاربری |
| Git & GitHub | مدیریت نسخه |
| PythonAnywhere | هاست رایگان |

## 🚀 اجرا روی سیستم خودت
\`\`\`bash
# کلون کردن پروژه
git clone https://github.com/yasinsaffayy-max/flask-todo.git
cd flask-todo

# نصب نیازمندی‌ها
pip install -r requirements.txt

# اجرا
python app.py
\`\`\`

سپس در مرورگر برو به: `http://127.0.0.1:5000`
